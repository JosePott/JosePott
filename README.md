## Mi enfoque

Me interesa conectar el desarrollo con problemas que conozco de cerca. El cuestionario de entrenamiento nació de mi experiencia como entrenador en McDonald's: una forma de convertir la práctica de procedimientos en una actividad interactiva.

## Tecnologías en mis proyectos

- **Interfaces:** React, Next.js, TypeScript, JavaScript, HTML y CSS.
- **Aplicaciones móviles:** Ionic y Capacitor.
- **Datos y servicios:** PostgreSQL, Prisma y Firebase.
- **Herramientas de desarrollo:** Git, Vite, ESLint, Vitest y Cypress.

Cada repositorio documenta su propósito, configuración y alcance actual.
